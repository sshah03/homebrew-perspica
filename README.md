# homebrew-perspica

Homebrew tap for [perspica](https://github.com/sshah03/perspica), which reviews code changes by what they do, not line by line.

```bash
brew install sshah03/perspica/perspica
```

Works on macOS (Apple silicon and Intel) and Linux (x86_64 and arm64). The formula installs the prebuilt binary from perspica's GitHub releases.
